# CaseOpenerPleerID — автоматический поиск Player ID

Android-приложение, которое **пытается найти Player ID в системном журнале**, пока запущена оригинальная игра Case Opener.

## Что делает
1. Пользователь один раз настраивает разрешение чтения логов через Android Debug Bridge (ADB).
2. В приложении нажимает «Начать поиск и открыть Case Opener».
3. Приложение запускает мониторинг логов в фоне с уведомлением и открывает оригинальную игру (`com.jakpok.casesimulator` — получено из предоставленного `base.apk`).
4. Когда лог содержит явную запись `Player ID: ...` или `playerId=...`, приложение показывает **возможный** Player ID, который можно скопировать.
5. Далее ID можно проверить через Telegram-бот VaultX.

Ввод Player ID вручную отсутствует. Не нужны удаление оригинальной игры, её переустановка, перехват аккаунта или изменение данных. Работает отдельное приложение-помощник.

## Важно: ограничение Android
Обычным приложениям Android **недоступны** логи других приложений. На совместимых устройствах требуется разрешение от владельца устройства через ADB:

```bash
adb shell pm grant online.vaultx.playeridhelper android.permission.READ_LOGS
```

Перед этим нужно включить «Для разработчиков» → «Отладка по USB» и установить ADB на ПК. На Android 13+ система может дополнительно запрашивать **разовое** разрешение чтения логов. На некоторых устройствах такой доступ вообще недоступен. Используйте только на собственном устройстве.

### Вторая важная граница
Доступ к `logcat` не гарантирует наличие ID: **если игра не записывает настоящий Player ID в системный журнал, извлечь его из журнала невозможно**. Мы пока не видели реальных логов оригинальной игры с подтверждённым Player ID, поэтому версия 0.2.0 — экспериментальный диагностический инструмент. Нужен реальный тест на устройстве.

Найденное совпадение в журнале не является доказательством владения игровым аккаунтом. Проверка через VaultX остаётся обязательной. Ни файлы игры, ни приватные каталоги Android это приложение не читает.

## Приватность
- Запись или отправка сырых системных логов отсутствует.
- ID, если обнаружен, хранится **только локально** в закрытых настройках приложения.
- Сохранён только текст одного кандидата и время обнаружения.
- Нет сервера, аналитики и права INTERNET.

## Компиляция
JDK 17, Android SDK 35, Gradle 8.9:

```bash
gradle assembleDebug
```

## APK
GitHub Actions → Android APK. Каждый успешный запуск публикует прямой `.apk` файл в GitHub Releases `v0.2.0`.

Оригинальное приложение **не заменяется**, а продолжает работать со своими данными и официальной подписью.
