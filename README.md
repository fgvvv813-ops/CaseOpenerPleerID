# CaseOpenerPleerID — VaultX Player ID Helper

Android-приложение-помощник для пользователей Case Opener.

## Возможности
- Открыть Telegram-бота VaultX для привязки игрового аккаунта и проверки Player ID.
- Ввести Player ID вручную и хранить его локально на устройстве.
- Скопировать сохранённый Player ID.
- Открыть оригинальный Case Opener, если он установлен.

**Важно:** приложение не читает приватные данные оригинальной игры и не может само получить ID без предоставленного API или доступа, разрешённого разработчиком игры. Введённый вручную ID не считается подтверждённым, пока он не проверен ботом.

**Оригинальная игра и её данные не изменяются.** Это приложение с собственным package ID, поэтому не заменяет и не обновляет оригинальный Case Opener.

## Сборка APK
GitHub Actions → Android APK → Run workflow (или commit в main).
Артефакт `caseopener-playerid-debug-apk` находится в завершённом запуске Actions.
Можно собрать локально: `gradle assembleDebug` (JDK 17, Android SDK 35).

## Безопасность
Никогда не добавляйте в публичный репозиторий Telegram BOT_TOKEN, conf.py с секретами, игровые токены или БД пользователей.
